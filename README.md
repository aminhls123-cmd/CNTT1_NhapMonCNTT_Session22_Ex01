# Bài 1 : Tìm kiếm tài liệu học tập chính thống bằng Google

## Lợi ích của toán tử `filetype:`
- **Tiết kiệm thời gian:** Dẫn trực tiếp đến file PDF gốc trên máy chủ trường, tránh việc phải click qua các trang web trung gian, blog rác, quảng cáo hoặc mã độc.
- **Loại bỏ nhiễu:** Toán tử `-studocu -123doc` giúp lọc bỏ các trang web thu phí hoặc nội dung không chính thống.
